**Status key**  Implemented means the described item exists. Verification is stated separately for each item. Partial means evidence or a capability covers only part of the criterion. Missing means the item is absent. Unverified means the required external or runtime evidence is unavailable. Confidence refers to this audit, never to likely marks.
